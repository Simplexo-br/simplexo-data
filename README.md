# Simplexo Data

Plataforma brasileira B2B de Data Intelligence e Sales Intelligence com Data Plane central, Application Plane em Odoo 18 Community e Intelligence Plane.

Os milhões de CNPJs não são replicados nos bancos Odoo nem viram `res.partner` automaticamente. Uma empresa só é promovida após seleção explícita.

## Estado

Fase 0 — Discovery e Arquitetura. Comece por `PROJECT_STATE.md` e siga a leitura seletiva definida em `AGENTS.md`; consulte estado/documentação detalhados somente quando a tarefa exigir. Nenhum módulo Odoo deve ser iniciado antes do gate técnico da Fase 0.

- GitHub Project: https://github.com/orgs/Simplexo-br/projects/13
- Git é a memória técnica; testes/CI são a verdade técnica; homologação e gates reservados exigem aprovação humana.
