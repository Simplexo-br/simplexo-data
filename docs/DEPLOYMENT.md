# Deployment Baseline

Ambientes isolados; infraestrutura versionada; secrets injetados; migrações forward-compatible; artefatos imutáveis promovidos. Addons devem instalar/atualizar limpos no Odoo 18 Community em servidores/bancos/domínios independentes. Só gateway é público. Produção exige backup, ensaio, smoke, observabilidade, rollback e change record.
