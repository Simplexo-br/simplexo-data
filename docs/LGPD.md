# LGPD Baseline

Dados de pessoa jurídica podem conter dados pessoais de sócios, representantes e contatos. Publicidade da fonte não elimina obrigações.

Exigidos: inventário; papéis controlador/operador; finalidade/base legal; minimização; qualidade; aviso/direitos; correção/export/delete; retenção; compartilhamentos/suboperadores; segurança/incidentes; RIPD quando aplicável; transferências; auditoria.

Scoring é estritamente comercial, não crédito/risco. Inferências precisam de provenance, contestabilidade e supervisão. Assessoria jurídica deve aprovar bases e termos; este documento não é parecer jurídico.
